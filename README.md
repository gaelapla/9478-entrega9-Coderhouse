# Skincare Pro

Sitio web de e-commerce enfocado en productos de skincare, desarrollado como proyecto final del curso de Desarrollo Web de Coderhouse.

## Descripción

Skincare Pro es un sitio de varias páginas que presenta una selección de productos para el cuidado de la piel, con secciones de información sobre la marca, preguntas frecuentes y contacto.

## Tecnologías utilizadas

- HTML5 (estructura semántica)
- CSS3 (Flexbox para maquetación)
- Google Fonts

## Estructura del proyecto

```
skincare-pro/
├── index.html
├── pages/
│   ├── productos.html
│   ├── sobre-nosotros.html
│   ├── preguntas-frecuentes.html
│   └── contacto.html
├── styles/
│   └── styles.css
├── images/
│   └── (imágenes de productos y del sitio)
└── README.md
```

## Cómo ver el proyecto

Este repositorio no cuenta con una demo online por el momento. Para verlo en tu computadora:

1. Cloná el repositorio:
   ```
   git clone https://github.com/gaelacarreira/skincare-pro.git
   ```
2. Abrí la carpeta en tu editor de código (por ejemplo, VS Code).
3. Abrí `index.html` con la extensión **Live Server** para verlo en el navegador correctamente (algunas funciones no cargan bien si se abre el archivo directamente con doble clic).

## Contexto

Este proyecto fue desarrollado como entrega final del curso **Desarrollo Web** de Coderhouse, con foco en la construcción de un sitio semántico y responsivo utilizando HTML y CSS con Flexbox.
